PK/PD and multiple endpoints

Where you are

So far every model had one endpoint, a drug concentration. Pharmacodynamic (PD) models describe a response. They can be linked to the pharmacokinetics and fitted together with the concentrations, used to compute a predicted effect from a PK fit, or stand on their own as an equation of time or dose. This chapter covers all three with the bundled examples.

WarningMaturity: stable, beta and experimental parts

The error models are stable in ferx-core. ODE models, [scaling] and [derived] are beta. Compartment-free models are documented in the ferx-core structural model page. See feature maturity.

Minimal runnable call: a joint PK/PD fit

The model has three ODE states: the depot, the central compartment and an effect compartment that follows the plasma concentration with rate KE0. [scaling] gives one readout per observed CMT (Observation scaling with [scaling]), and [error_model] one residual error model per CMT:

invisible(ferx_model_get_section(pkpd$model, "odes"))
#> # [odes]
#>   d/dt(depot)   = -KA * depot
#>   d/dt(central) =  KA * depot - CL/V * central
#>   d/dt(effect)  =  KE0 * (central/V - effect)
invisible(ferx_model_get_section(pkpd$model, "scaling"))
#> # [scaling]
#>   y[CMT=2] = central / V                                  # plasma conc (mg/L)
#>   y[CMT=3] = E0 + EMAX * effect^GAMMA / (EC50^GAMMA + effect^GAMMA)  # Emax PD
invisible(ferx_model_get_section(pkpd$model, "error_model"))
#> # [error_model]
#>   CMT=2: DV ~ proportional(PROP_ERR_PK)   # central compartment (PK)
#>   CMT=3: DV ~ additive(ADD_ERR_PD)        # effect compartment (PD)
invisible(ferx_model_get_section(pkpd$model, "fit_options"))
#> # [fit_options]
#>   method     = focei
#>   maxiter    = 500
#>   covariance = true
#>   gradient   = fd                         # required: per-CMT / Form C readout
fit_pkpd <- ferx_fit(pkpd$model, pkpd$data, gradient = "auto", verbose = FALSE)
#> Warning: Model file [fit_options] sets `gradient = fd` but ferx_fit() argument
#> overrides it with `auto`. The call-time value will be used.

Both endpoints enter one likelihood, so the PK and PD parameters are estimated together. The model file asks for gradient = fd, and its comment calls finite differences required for this readout. At this build they are not, and the comment is out of date (ferx-core #1625): ferx computes the analytic gradient for this model (fit_pkpd$gradient_used is “analytic”), and the R warning above reports the override. The fits in this chapter pass gradient = "auto", because the finite-difference fit stops short of the optimum, as the simulation–estimation run below shows.

Options that matter

Where Syntax Meaning
Data CMT on observation rows Which endpoint the row is
[structural_model] ode(states=[depot, central, effect]) No single obs_cmt; [scaling] defines each readout
[scaling] y[CMT=2] = central / V, y[CMT=3] = <expr> One readout per observed CMT
[error_model] CMT=2: DV ~ proportional(...), CMT=3: DV ~ additive(...) One residual error model per CMT (ODE models only)
[structural_model] y = <expr> with no pk or ode line A compartment-free model
[derived] EFF = EMAX * IPRED / (EC50 + IPRED) An effect computed from a PK fit

Every observed CMT needs a readout and an error model. The two forms cannot be mixed in one block (error model).

Variants

Simulation and estimation: can a design support the model?

To see whether the joint model can be estimated with a realistic design, simulate a study from the model’s initial values and fit it again. simulate_study() below writes a design, simulates it once with ferx_simulate() (without fit, so with the model file’s parameters, Simulating scenarios) and returns the simulated study as a data file. The first design is the bundled one, scaled up: 30 subjects on 100, with six concentration and six effect samples each. recovery() puts each estimate beside the value it was simulated with:

simulate_study <- function(doses, file, seed = 42) {
  ids <- seq_along(doses)
  design <- bind_rows(
    data.frame(ID = ids, TIME = 0, DV = NA, EVID = 1, AMT = doses, CMT = 1, RATE = 0, MDV = 1),
    expand.grid(ID = ids, TIME = c(0.5, 1, 2, 4, 8, 12)) |>
      mutate(DV = NA, EVID = 0, AMT = NA, CMT = 2, RATE = 0, MDV = 0),
    expand.grid(ID = ids, TIME = c(1, 2, 4, 8, 12, 24)) |>
      mutate(DV = NA, EVID = 0, AMT = NA, CMT = 3, RATE = 0, MDV = 0)
  ) |> arrange(ID, TIME, desc(EVID), CMT)
  design_file <- sub("\\.csv$", "_design.csv", file)
  write.csv(design, design_file, row.names = FALSE, na = ".")
  # the empty DV cells are the points to simulate, which ferx notes as W_DESIGN_DV
  simulated <- suppressWarnings(ferx_simulate(pkpd$model, design_file, n_sim = 1, seed = seed))
  rows <- design$EVID == 0
  design$DV[rows] <- simulated$DV_SIM[match(paste(design$ID, design$TIME, design$CMT)[rows],
                                            paste(simulated$ID, simulated$TIME, simulated$CMT))]
  write.csv(design, file, row.names = FALSE, na = ".")
  file
}
recovery <- function(f) {
  data.frame(parameter = c(names(f$theta), f$eta_names, f$sigma_names),
             simulated_with = c(f$theta_init, f$omega_init[c(1, 4)], f$sigma_init),
             estimate = c(f$theta, diag(f$omega), f$sigma),
             rse_pct = f$estimates$rse_pct)
}

WarningThe model file’s finite-difference gradient stops short at this build

The fits above pass gradient = "auto". With the model file’s own gradient = fd, the fits of both designs converge well above their optimum, and refitting with a gradient-based optimizer, as Estimation methods and controlling the fit suggests when bobyqa stops on a slope, does not rescue them:

gradient_runs <- function(data, fit_auto) {
  list(`gradient = fd (model file)` = ferx_fit(pkpd$model, data, verbose = FALSE),
       # suppress the R warning that reports overriding the model file's optimizer
       `gradient = fd, optimizer = slsqp` = suppressWarnings(
         ferx_fit(pkpd$model, data, settings = list(optimizer = "slsqp"), verbose = FALSE)),
       `gradient = "auto"` = fit_auto)
}
fd_runs <- list(`100 for all` = gradient_runs(one_dose, fit_one_dose),
                `100, 300, 1000` = gradient_runs(dose_range, fit_dose_range))
do.call(rbind, lapply(names(fd_runs), function(design) {
  do.call(rbind, lapply(names(fd_runs[[design]]), function(run) {
    f <- fd_runs[[design]][[run]]
    data.frame(design = design, fit = run, ofv = f$ofv, TVEMAX = f$theta[["TVEMAX"]],
               TVEC50 = f$theta[["TVEC50"]], max_rse_pct = max(f$estimates$rse_pct))
  }))
}))

Every finite-difference fit stops between 3.2 and 11.4 OFV points above the optimum that the analytic gradient finds. The objective is the same on both paths (the analytic optimum scores the same OFV on the finite-difference path), so it is the gradient that loses the optimum. On the 100 design this is the trap of a simulation–estimation run: the fit starts at the simulation values and stops near them, so TVEMAX comes out close to 40 and the design looks able to support the model, which it is not. Fit a simulated study with the most reliable settings you have, and compare its OFV with the objective at the simulation values. For this model, pass gradient = "auto" until the model file drops its gradient = fd (ferx-core #1625).

Models without compartments

Wherever CMT selects something this is a guess rather than a default, and a wrong guess changes the numbers with no error: which compartment a dose lands in (an `[odes]` model with several states, or a `pk` model whose CMT=2 is a real target — an oral model's central bolus, a multi-compartment model's peripheral), and which readout, scale or error model an observation uses. Writing CMT=1 explicitly on every row silences this.
#>   W_NO_DOSES: parsed zero dose events across all 30 subject(s) although scored observations are present. If this is a PK model, check that the dataset has an AMT column with EVID=1/4 dose rows (or a nonzero AMT when EVID is absent).

A compartment-free model cannot have [odes], [scaling] or references to central and depot. y[CMT=N] gives it several endpoints (structural model).

Pitfalls

  • Joint PK/PD models need data for every parameter. Check relative standard errors and correlations before interpreting PD parameters; a simulation–estimation run tells whether a design can support the model.
  • An Emax design has to reach the EC50. With concentrations that stay below it, EMAX and EC50 cannot be told apart, whatever the number of subjects, and their standard errors need not say so. Compare the fit’s OFV with the objective at the simulation values: a fit that stops near its starting values looks like a recovery.
  • Per-CMT error models need an ODE model. An analytical pk model with CMT=N: lines is rejected. Use ode_template to write the PK part as ODEs.
  • Every observed CMT needs a readout and an error model. A missing entry stops the fit and names the compartment.
  • Thresholds that are never crossed give NaN in [derived] filters and conditional integrals.

Warnings you may see here

  • general (warning): parameters declared but not used by the predictions, such as the fixed PD thetas of warfarin_derived_pkpd that only [derived] reads.

Other warnings above (inflated_rse, high_correlation, condition_number) are covered in Parameter uncertainty.

Summary

  • Put all endpoints in one dataset and tell them apart with CMT.
  • Write the PK and PD states as ODEs, one [scaling] readout and one error model per CMT, and fit them jointly.
  • Check with simulation and estimation whether a design can support the PD parameters.
  • Compute effects from a PK fit with [derived] when the PD parameters are known.
  • Write responses that are plain equations as compartment-free models.
